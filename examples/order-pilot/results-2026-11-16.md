# First order lookup pilot: apparatus feedback, not an adoption claim

One participant completed 18 tasks: three practices and fifteen measured tasks.
Afterward, the participant clarified that **all tasks were typed alone**, without
a second person reading codes. Six paste trials and three spoken trials are
therefore excluded. One manual alias trial is also excluded because the browser
recorded a blocked paste attempt. They are not relabelled as manual trials.

The original export is preserved unchanged. The accompanying
[anonymized observations and analysis](results-2026-11-16.json) omit code values,
participant identity and exact timestamps. They retain all fifteen measured
rows, explicit exclusions, the raw export checksum and the two timing metrics.

| Manual format | Eligible successes / planned | Median first correct lookup | Median explicit confirmation | Query errors |
| --- | --- | --- | --- | ---: |
| UUID | 2 / 2 | 41.5 s | 43.0 s | 1 |
| Eight-symbol alias | 1 / 2 | 6.9 s | 18.1 s | 0 |
| RefMint | 2 / 2 | 16.6 s | 17.4 s | 0 |

These five valid observations do **not** establish a practical advantage. In
particular, the alias's confirmation delay reverses the apparent ordering of
alias and RefMint if only total time is shown. Its single valid trial is not a
reliable comparative estimate. No valid paste or spoken comparison remains, and
no population error rate or confidence claim is made. Keep the existing alias
unless a real workflow demonstrates enough benefit to justify the extra format.

The pilot identified a problem with the apparatus: mode instructions disappeared
when a task started. Instructions now remain visible throughout entry; missing
paste events are explained before confirmation, exclusions are shown afterward,
and JSON can be displayed directly when the download is hard to find. Automated
tests check these changes and actual Chromium clipboard delivery. They are not
replacement participant observations. A future study should use the corrected
instructions, a separate participant session and the predeclared modes.
